# Uzumaki — Releases

This repo hosts **built releases of Uzumaki** (`Uzumaki.exe`) only — no source
code lives here.

Source: private repo (not public). This repo exists purely so `Uzumaki.exe`'s
built-in auto-updater can download new builds anonymously, without needing an
embedded credential to a private repo.

See the [**Releases**](../../releases/tag/latest) page for the latest build.
